# `@agenthawk/core`

Deterministic policy, evidence, provider, approval, cache, and report schemas for [AgentHawk](https://github.com/nafiyad/AgentHawk).

This package is pre-release and remains private until package ownership and release controls are confirmed. Its schemas do not declare a dependency safe; they validate AgentHawk's evidence and policy contracts.

See the repository [architecture](https://github.com/nafiyad/AgentHawk/blob/main/docs/architecture.md), [threat model](https://github.com/nafiyad/AgentHawk/blob/main/docs/threat-model.md), and [JSON contract](https://github.com/nafiyad/AgentHawk/blob/main/docs/json-contract.md).
